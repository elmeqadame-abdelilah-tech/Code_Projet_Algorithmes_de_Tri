## Prerequis

- GCC (MinGW-w64) et mingw32-make
- gnuplot (dans le PATH) pour afficher les graphes

## Compilation et execution

    mingw32-make
    mingw32-make run
    mingw32-make clean

## Organisation du projet

- src/ : code source (un module = un .c)
- include/ : fichiers d'en-tete (.h)
- data/ : fichier d'entiers genere
- results/ : resultats du lancer (.dat)
- graphs/ : scripts gnuplot (.gp)
